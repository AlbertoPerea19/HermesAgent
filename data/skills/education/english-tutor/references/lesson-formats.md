# Lesson formats

Rotate the focus block so every skill appears at least twice a week. Pick the skill with the weakest recent results first.

| Format | 12-18 minute structure |
|---|---|
| Reading | 1 short passage (B2-C1, academic or daily life), 3-4 questions, then discuss one inference |
| Writing | A 60-100 word task (email or academic discussion), then 2 targeted corrections and a rewrite of one sentence |
| Vocabulary | 6-8 new academic words in context, a gap-fill, then use two in own sentences |
| Grammar | One pattern from `Errors.md`, 5 contrast items, then 2 free sentences |
| Listening (text proxy) | A short transcript read once, then 3 detail and inference questions without re-reading |
| Speaking (text proxy) | An interview-style question, a 60-90 word spoken-style answer in writing, feedback on organization and fluency markers |

Source material: choose topics useful for academic English (campus life, science, society, technology). For real transcripts use the `youtube-content` skill and cite the source.

Difficulty control: if the learner gets more than 80% right, raise one level next block; below 50%, lower one level and add scaffolding.
