# TOEFL iBT format (approximate)

Reported by third-party guides as of 2026; confirm against official ETS materials before relying on any detail.

- Score scale: bands 1-6 in half-point steps, aligned with CEFR; reports also show the older 0-120 total for a transition period. Overall = average of the four sections.
- C1 corresponds to about band 5; guides disagree on exact half-band mappings, so treat it as a target range (5.0-5.5).
- Reading and Listening are multistage adaptive. Writing and Speaking are linear. Order: Reading, Listening, Writing, Speaking.
- Writing task types: build a sentence, write an email, write for an academic discussion.
- Speaking task types: listen and repeat, take an interview.
- Reading task types: complete the words, read in daily life, read an academic passage.
- Listening task types: respond to a short prompt, conversation, announcement, academic talk.

Use these only to shape practice tasks. If the learner asks for exact official rules, say it must be checked with ETS.
